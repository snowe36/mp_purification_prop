# mp-atlas

**Cellular expression is not HTS-studyable material.** This repo measures that gap on public catalogs. Numbers land in the README after `mpx-demo` / Gate 0.

See `ANALYSIS.md` for the pre-registered questions. Quick start is in that file’s spirit: install, `mpx-demo`, then `mpx-download` and `mpx-census`.

```bash
python3.11 -m venv .venv && source .venv/bin/activate
pip install -e ".[dev]"
mpx-demo
```
